Python Looping Cheatsheet
==========================

We will use this array for examples:
------------------------------------
arr = [10, 20, 30, 40]
n = len(arr)   # n = 4 elements

-------------------------------------------------
1. For Loop with Direct Iteration over Elements
-------------------------------------------------
for val in arr:
    print(val)

# Output:
10
20
30
40

👉 Iterates directly over values (no index).

-------------------------------------------------
2. For Loop with range(len(arr)) → Index Access
-------------------------------------------------
for i in range(len(arr)):    # i = 0,1,2,3
    print(i, arr[i])

# Output:
0 10
1 20
2 30
3 40

👉 Covers all indices 0 → n-1.

-------------------------------------------------
3. For Loop with range(len(arr)-1) → Skips Last
-------------------------------------------------
for i in range(len(arr)-1):  # i = 0,1,2
    print(i, arr[i])

# Output:
0 10
1 20
2 30

👉 Skips last element (arr[3] = 40).

-------------------------------------------------
4. For Loop with Enumerate → Index + Value
-------------------------------------------------
for i, val in enumerate(arr):
    print(i, val)

# Output:
0 10
1 20
2 30
3 40

👉 Best way when you need both index and value.

-------------------------------------------------
5. While Loop with Index
-------------------------------------------------
i = 0
while i < len(arr):    # 0,1,2,3
    print(i, arr[i])
    i += 1

# Output:
0 10
1 20
2 30
3 40

👉 Includes last element.

-------------------------------------------------
6. While Loop with len(arr)-1 → Skips Last
-------------------------------------------------
i = 0
while i < len(arr)-1:  # 0,1,2
    print(i, arr[i])
    i += 1

# Output:
0 10
1 20
2 30

👉 Skips last element.

-------------------------------------------------
7. While Loop with Two Pointers
-------------------------------------------------
l, r = 0, len(arr)-1   # l=0, r=3
while l < r:
    print(l, arr[l], "|", r, arr[r])
    l += 1
    r -= 1

# Output:
0 10 | 3 40
1 20 | 2 30

👉 Starts at both ends and moves inward.

-------------------------------------------------
8. While Loop with "while arr:" → Truthy Check
-------------------------------------------------
temp = arr.copy()
while temp:
    print(temp.pop(0))

# Output:
10
20
30
40

👉 Condition checks if list is non-empty. 
Keeps looping until list becomes empty.

-------------------------------------------------
9. For Loop with range(start, stop, step)
-------------------------------------------------
for i in range(0, len(arr), 2):   # step = 2
    print(i, arr[i])

# Output:
0 10
2 30

👉 Useful for skipping elements.

-------------------------------------------------
10. List Comprehension (Compact Loop)
-------------------------------------------------
squares = [x*x for x in arr]
print(squares)

# Output:
[100, 400, 900, 1600]

👉 Pythonic, used in real projects for transformations.

-------------------------------------------------
Summary of Looping Methods
-------------------------------------------------
- for val in arr → values only
- for i in range(len(arr)) → indices
- for i,val in enumerate(arr) → index + value
- while i < len(arr) → index-based loop
- while arr → empties the list until done
- two pointers (while l<r) → common in DSA problems
- range(start, stop, step) → custom stepping
- list comprehensions → clean & fast
